  PORTFOLIO WEBSITE - HOW TO RUN (For Python Developers)
================================================================================

THIS IS NOT A JAVA PROJECT - THIS IS A NODE.JS (JAVASCRIPT) PROJECT!

================================================================================
STEP 1: INSTALL NODE.JS (Only Once)
================================================================================

If Node.js is not installed:
  1. Open https://nodejs.org/
  2. Download the "LTS" version (left side)
  3. Install it (keep default options)
  4. Restart your computer
  5. Verify: Open terminal and type "node --version"
     If a version number appears, it's successful! ✓

================================================================================
STEP 2: AUTOMATIC SETUP (EASY WAY - RECOMMENDED)
================================================================================

For Windows Users:
  1. Double-click the START.bat file
  2. Everything will be installed automatically
  3. After setup is complete, follow the steps below

================================================================================
STEP 3: MANUAL SETUP (If automatic setup doesn’t work)
================================================================================

TERMINAL 1 - Backend Setup:
---------------------------
1. Open Terminal/PowerShell
2. Type:
   cd backend
   npm install
   
3. Create a .env file:
   - Open "env.example.txt" inside backend folder
   - Copy all content
   - Create a new file named ".env" (starting with a dot)
   - Paste the content

4. Start backend:
   npm start
   
   You should see:
   "🚀 Server running on port 5000"
   
   ⚠️ KEEP THIS TERMINAL OPEN (server is running)


TERMINAL 2 - Frontend Setup (NEW TERMINAL):
--------------------------------------------
1. Open a NEW Terminal/PowerShell (don’t close the first one!)
2. Type:
   cd frontend
   npm install
   npm start
   
3. Browser will automatically open at:
   http://localhost:3000


================================================================================

================================================================================
COMMON ERRORS & SOLUTIONS
================================================================================

Error: "node command not found"
  → Node.js is not installed
  → Install it from https://nodejs.org/

Error: "Port already in use"
  → Port 5000 or 3000 is already in use
  → Change backend port in .env file: PORT=5001
  → For frontend: use PORT=3001 in terminal

Error: "npm install failed"
  → Check internet connection
  → Run: npm cache clean --force
  → Then run npm install again

Error: "Module not found"
  → Make sure you're in correct folder (backend/frontend)
  → Delete node_modules
  → Run npm install again
